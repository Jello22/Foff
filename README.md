# F Off

Because apparently `F` was load-bearing.

F Off is a lightweight, client-side Valheim mod that lets you rebind the hardcoded **Filter** key in the build menu.

The default is still `F`, but now you can make it whatever the F you want.

The on-screen key hint updates to match your selected key.

## Features

- Rebind the build-menu Filter key
- Updates the on-screen key hint
- Changes take effect immediately
- Client-side only
- No server installation required
- Other players do not need the mod
- Controller support remains unchanged

## Configuration

With BepInEx ConfigurationManager installed, open the configuration menu and find:

`F Off > Build Menu > Filter Key`

Default: `F`

Use **Reset** to restore the default key.

## Installation

Use Gale Mod manager

## Manual Installation

Requires BepInEx for Valheim.

Install `FOff.dll` into:

`BepInEx/plugins/FOff/`


## Multiplayer

F Off is entirely client-side.

However has not been extensively tested in MP but shouldn't be an issue.
